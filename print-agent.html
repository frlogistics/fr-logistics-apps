Leave this tab open
This tab is the printer. If it is closed, boxes can still be sealed on the handheld and their labels queue up here — nothing is lost — but nothing prints until it is reopened.

Chrome must be launched with --kiosk-printing, and the MUNBYN ITPP129S (USB) must stay as the Windows default printer. Labels go to whichever printer Windows calls default; there is no way to pick one from here.
